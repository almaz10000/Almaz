# Weather Diary
**Автор:** [Ваше Имя]

### Описание
Программа для ведения ежедневника погоды. Позволяет фиксировать температуру, состояние неба и наличие осадков, сохраняя историю в JSON.

### Как запустить
1. Установите Python 3.x.
2. Скачайте `weather_diary.py`.
3. Запустите через терминал: `python weather_diary.py`.

### Примеры использования
- Введите `01.05.2024`, `15`, `Солнечно`, снимите галочку "Осадки" и нажмите "Добавить".
- Чтобы найти теплые дни, введите `10` в поле фильтра и нажмите "Применить".
